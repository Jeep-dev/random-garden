批量提交助手 v0.2.2 —— 安装与使用

【安装】
1. 把压缩包解压,得到文件夹 batch-submit(里面 5 个文件:manifest.json、background.js、inject.js、popup.html、popup.js)。
   解压后文件夹不要删、不要移动,浏览器每次启动都从这个位置读取它。
2. 地址栏输入 edge://extensions 回车(Chrome 用 chrome://extensions)。
3. 打开「开发人员模式」开关。
4. 点「加载解压缩的扩展」,选择 batch-submit 文件夹。
5. 点浏览器右上角的拼图图标,把「批量提交助手」固定出来。

【第一次使用:一定按这个顺序】
1. 停在平台的任意一个任务标签页上,点扩展图标。「域名包含」会自动填成当前页的域名。
2. 保持默认:勾选「试运行」、「最多处理 1 个」。点「开始」。
   试运行会走到确认弹窗并选好「质检通过」,然后点「取消」,不会真的提交。
   结果显示「可提交」,说明三步都点对了。
3. 取消勾选「试运行」,仍然只处理 1 个。点「开始」,再点一次「再点一次:真实提交 1 个」(5 秒内)。
   这个任务会真的提交,并点「返回主页领取新任务」。
4. 没问题再把「最多处理」改成 0(不限),并发数建议 5。

【结果状态】
成功    已提交,并已点「返回主页领取新任务」
可提交  试运行走通了,没有提交
失败    出错。「提交之前」出错的可以点「重跑失败项」;「提交后报错」的不会重跑,请到该标签页查看
未知    已点最终提交但 30 秒内没看到结果。请手动确认任务状态,不要重试
跳过    不是任务页 / 页面上没有「任务有效」 / 被停止,没有动任何东西
没有顶栏「提交」按钮的标签页(比如平台主页)开始前就排除掉,不会处理,也不占「最多处理」的名额。
连续 3 个失败会自动停止,剩下的标记为「跳过」。点结果列表里的某一行可以跳到对应标签页。

【如果平台文案和脚本不一致】
打开 inject.js,最上面的 CFG 里是所有文案(质检通过、任务有效、提交任务成功、返回主页领取新任务 等)。
改完后在 edge://extensions 点该扩展的刷新按钮即可。
如果平台页面上没有「任务有效」字样,把 READY_TEXT 改成 '' 即可关闭这个检查。
